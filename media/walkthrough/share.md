# Sharing on the Hub

**Package** writes `<Name>.nc` next to the handler: `handler.js` plus the files in its `<Name>/` folder, laid out the way the Hub install expects.

Upload it at [hub.splitscreen.me](https://hub.splitscreen.me/). Players then find it in Nucleus' own handler browser.

A handler with errors isn't packaged without asking: Nucleus might not load it.

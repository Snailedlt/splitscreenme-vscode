# Testing in Nucleus Co-op

1. **Test in Nucleus Co-op** (the ▷ button above a handler) puts `<Name>.js` and its `<Name>/` folder in Nucleus' `handlers` folder and starts Nucleus with the game selected. An open Nucleus is restarted (with your OK): it reads handlers when it starts.
2. The first time, say yes to the debug log (or turn it on in Nucleus' *Settings*).
3. Pick 2 players and press Play. A game that isn't in your list yet is added once, by its .exe.
4. Something off? `debug-log.txt` in the Nucleus folder says what Nucleus did. Problems with windows, focus or input often have a tip in the hover of the option that controls them.

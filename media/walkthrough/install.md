# Testing in Nucleus Co-op

1. **Install** puts `<Name>.js` and its `<Name>/` folder in Nucleus' `handlers` folder. If it's already there, you're asked first.
2. In Nucleus, turn on the debug log: *Settings*, or `DebugLog=True` under `[Misc]` in Nucleus' `Settings.ini`.
3. Start the game with 2 players.
4. Something off? `debug-log.txt` in the Nucleus folder says what Nucleus did. Problems with windows, focus or input often have a tip in the hover of the option that controls them.
